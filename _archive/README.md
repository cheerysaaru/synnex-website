# Archive

`backend-old-scaffold/` is the first Laravel/PostgreSQL scaffold. It was replaced by the
full Laravel app now in `../backend/`, which contains everything this one did. It also
includes the `docker-compose.yml` for PostgreSQL, if you move to Postgres later.
It's safe to delete this folder.

`switchboard-home/` is the "Switchboard" home page design (breaker board, circuit schedule).
To bring it back, copy both files into `frontend/src/` (HomePage.jsx into `src/pages/`).
